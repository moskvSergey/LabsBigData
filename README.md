# Лабораторная работа 1: Анализ Big Data-сценариев

## О работе

Анализ датасета **MovieLens ml-32m** (32 млн оценок фильмов, 1995–2023) 
под бизнес-сценарий **рекомендательной системы** для онлайн-кинотеатра.

## Что внутри

- `lab1.ipynb` — Jupyter Notebook с полным анализом по 5V
- `ml-32m/` — папка для данных (файлы не коммитятся, см. `.gitignore`)

## Структура анализа

1. **Volume** — объём данных, форматы хранения (CSV/Parquet/Avro), 
   рост по годам, стоимость в облаке, Pandas vs Spark
2. **Velocity** — скорость поступления, пиковые нагрузки, 
   выбор режима обработки (batch / micro-batch / streaming)
3. **Variety** — типы данных, разбор неструктурированного текста, 
   схема хранения
4. **Veracity** — пропуски, дубликаты, аномалии, проверки 
   через Great Expectations
5. **Value** — ROI рекомендательной системы, ABC-анализ, 
   мониторинг ценности
6. **Технологии** — выбор стека, архитектура, roadmap на 6 месяцев

## Ключевые выводы

| Критерий | Результат |
|---|---|
| Volume | 0.2 ГБ в Parquet, ~30 МБ/год прироста, хранение < 10 ₽/год |
| Velocity | 0.035 записей/сек в среднем, пик 548× выше, нужен streaming |
| Variety | 93.6% числовых, < 1% текста, тяжёлый NLP не нужен |
| Veracity | 0 дубликатов, 0 аномалий, пропуски < 0.9% в неключевых полях |
| Value | ROI положительный, окупаемость ~6–12 мес |

## Технологический стек

S3 + Delta Lake + Spark + Kafka + MLflow + FastAPI + Airflow + Great Expectations.
